## DESIGN & STYLE GUIDELINES:
- **Color Palette:** Dark theme — Dark navy (#0a0f2c) or charcoal (#1a1a2e) backgrounds. Accent: electric blue (#00d4ff) and vibrant green (#00e676). White text. Cards: slightly lighter dark (#1e1e3f) with subtle borders.
- **Typography:** Modern sans-serif — Inter or Plus Jakarta Sans. Bold headlines (700-800 weight), clean body (400-500 weight).
- **Style:** Premium SaaS/agency hybrid. Clean spacing, generous whitespace, subtle glassmorphism on nav and cards.
- **Animations:** Scroll-triggered fade-in and slide-up (AOS-style). Count-up numbers in stats section. Smooth hover effects (glow, lift, scale) on buttons and cards. Subtle gradient animation on hero background.
- **Responsive:** Fully mobile-responsive. Mobile-first approach since traffic comes from TikTok and WhatsApp.
- **Performance:** Lightweight, fast-loading. Optimize for Core Web Vitals.
